


1. python classes - provide a means of bundling data and functionality together. 
Creating a new class creates a new type of object, allowing new instances of that type to be made. 
Each class instance can have attributes attached to it for maintaining its state. 
Class instances can also have methods (defined by its class) for modifying its state.

2. Git is a distributed version control system that helps developers track changes, 
collaborate with others, and manage project history efficiently.
To create a full machine learning project with Git, 
start by creating a project folder and initializing a repository with git init. 
A typical project structure may include folders such as data, notebooks, src, models, 
and reports, along with files like README.md, requirements.txt, and .gitignore. 
The .gitignorefile is important because it prevents unnecessary or sensitive 
files such as large datasets, temporary outputs, and environment files from being tracked.

3. Logging - defines functions and classes which implement a 
flexible event logging system for applications and libraries.

The key benefit of having the logging API provided by a standard library 
module is that all Python modules can participate in logging, so your 
application log can include your own messages integrated with messages from third-party modules.

# myapp.py
import logging
import mylib
logger = logging.getLogger(__name__)

def main():
    logging.basicConfig(filename='myapp.log', level=logging.INFO)
    logger.info('Started')
    mylib.do_something()
    logger.info('Finished')

if __name__ == '__main__':
    main()


# mylib.py
import logging
logger = logging.getLogger(__name__)

def do_something():
    logger.info('Doing something')

4. Loading data

Data Loading can be done with simple ways using logs and without logs.
It can also be done with python classes src+ipynb files.

Data loading is the process of reading raw data 
from a source (CSV, database, API) 
into memory as a usable format (pandas DataFrame) for the ML pipeline. 
It's the first step of every ML pipeline.

5.                 What's Logging

Logging is the process of documenting each step of the project.
Logs folder created in ML projects and necessary files will be created 
inside of that folder. 

How can we write into that logging files?!
We can write logs in notebook files and in classes in src/ folders 
when the code is broken or when the classes malfunction the logs 
will be added into that log files inside the logs/ folder.

The levels work like this:

DEBUG = very detailed information
INFO = normal progress
WARNING = problem, but code can continue
ERROR = something failed
CRITICAL = serious failure

format=... controls how each line looks inside review.log.

6. A pipeline is a chain of steps that automatically processes data in order
from raw data to final prediction 
where the output of each step becomes the input of the next.

with pipeline >>>>>>>>>>>>

from sklearn.pipeline import Pipeline

pipe = Pipeline([
    ('scaler',  MinMaxScaler()),
    ('encoder', OrdinalEncoder()),
    ('model',   RandomForestRegressor())
])

pipe.fit(X_train, y_train)      
predictions = pipe.predict(X_test)
