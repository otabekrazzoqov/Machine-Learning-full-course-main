// 14-step guide: raw data → production model

Raw Data → EDA → Preprocessing → Feature Eng. → Encoding → Scaling → Split → Train → Evaluate → Tune → Save → Deploy
Phase 1 — Problem Setup
01 / Problem Definition

Define the Task

  • Identify task type: regression or classification
  • Understand the business goal and success criteria
  • Define measurable success metrics upfront
  • Regression → predict continuous values (price, score)
  • Classification → predict discrete labels (spam, churn)
02 / Data Collection

Load & Understand Data

  • Understand data source, provenance, and context
  • Check for bias or sampling issues in collection

Phase 2 — Analysis
03 / EDA

Exploratory Data Analysis

  • Distributions: histplot, boxplot for skew & spread
  • Correlations: heatmap to find feature relationships
  • Target analysis: class balance, value distribution
  • Outlier detection: IQR method or z-score

04 / Preprocessing

Clean the Data

python 
# Missing values
df.fillna(df.median(), inplace=True)   # numeric
df.fillna(df.mode()[0], inplace=True)  # categorical
df.dropna(subset=['critical_col'])     # required cols

# Duplicates
df.drop_duplicates(inplace=True)

# Data types
df['date'] = pd.to_datetime(df['date'])

# Outliers (IQR clip)
Q1, Q3 = df['col'].quantile([0.25, 0.75])
IQR = Q3 - Q1
df['col'] = df['col'].clip(Q1-1.5*IQR, Q3+1.5*IQR)
Phase 3 — Feature Engineering
05 / Feature Engineering

Create Better Features

python 
# Interaction features
df['price_per_sqft'] = df['price'] / df['sqft']

# Aggregation features
df['mean_by_group'] = df.groupby('cat')['val'].transform('mean')

# Log transform (skewed distributions)
import numpy as np
df['log_income'] = np.log1p(df['income'])

# Binning continuous variables
df['age_group'] = pd.cut(df['age'],
    bins=[0,18,35,60,100],
    labels=['minor','young','adult','senior'])
06 / Encoding

Encode Categoricals

python 
from sklearn.preprocessing import (
    LabelEncoder, OrdinalEncoder, OneHotEncoder
)

le = LabelEncoder()
df['gender_enc'] = le.fit_transform(df['gender'])

# Ordinal Encoding — ordered categories
oe = OrdinalEncoder(categories=[['low','med','high']])
df['size_enc'] = oe.fit_transform(df[['size']])

# One-Hot Encoding — nominal categories
df = pd.get_dummies(df, columns=['city'], drop_first=True)
07 / Scaling

Scale Numeric Features

Scaler Formula Best For Skip When
StandardScaler (x − μ) / σ Linear models, SVM, PCA, Logistic Regression Tree-based models
MinMaxScaler (x − min) / (max − min) Neural networks, KNN, bounded features Tree-based models, heavy outliers
RobustScaler (x − median) / IQR Data with many outliers Normally distributed data
Tree Models — RandomForest, XGBoost, LightGBM → skip scaling entirely

Split the Dataset

10 / Model Evaluation

Measure Performance

MAE MSE RMSE R² Accuracy F1-Score AUC-ROC Cross-Validation
python 
from sklearn.metrics import (
    mean_absolute_error, mean_squared_error, r2_score,  # regression
    accuracy_score, f1_score, roc_auc_score             # classification
)
from sklearn.model_selection import cross_val_score

y_pred = model.predict(X_test)

# Regression
print("MAE :", mean_absolute_error(y_test, y_pred))
print("RMSE:", mean_squared_error(y_test, y_pred, squared=False))
print("R²  :", r2_score(y_test, y_pred))

# Cross-validation (k=5)
scores = cross_val_score(model, X, y, cv=5, scoring='r2')
print(f"CV R²: {scores.mean():.3f} ± {scores.std():.3f}")

    return {"prediction": model.predict(X)[0]}
